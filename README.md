# dev-free-toolkit

Skills gratuitos de Claude para emprendedores y pymes que trabajan con proyectos hechos con IA (Lovable, Bolt, Cursor, v0, ChatGPT, Claude…).

## Qué incluye

| Skill | Qué hace |
|---|---|
| `auditoria-seguridad` | Revisa la seguridad de tu proyecto y te entrega una página visual con los riesgos para tu negocio, qué podría pasar y qué arreglar primero, más un informe técnico para quien lo arregle. |

## Cómo instalarlo

### En Claude Code

Dentro de Claude Code, escribí:

```
/plugin marketplace add garciawarneckee/dev-free-toolkit
/plugin install dev-free-toolkit@dev-free-toolkit
```

Después abrí tu proyecto y pedí, por ejemplo: *"auditá la seguridad de este proyecto"*.

### En claude.ai (web o app de escritorio)

En **Customize › Plugins › Add marketplace**, pegá `garciawarneckee/dev-free-toolkit`.

## Qué necesitás

Solo Claude. Si tenés Python instalado, el skill lo usa para validar el informe; si no, funciona igual.
